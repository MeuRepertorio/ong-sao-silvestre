# ONG São Silvestre — Site institucional

Site institucional responsivo da ONG São Silvestre.

## Estrutura

- `index.html` — página principal com HTML, CSS, JavaScript e imagens incorporadas.
- `.nojekyll` — permite servir os arquivos diretamente pelo GitHub Pages.

## Visualizar localmente

Abra o arquivo `index.html` no navegador. Não é necessário instalar dependências.

## Publicar no GitHub Pages

1. Envie os arquivos para a **raiz** da branch `main` do repositório.
2. No GitHub, abra **Settings > Pages**.
3. Em **Build and deployment**, escolha **Deploy from a branch**.
4. Escolha a branch `main` e a pasta `/(root)` e clique em **Save**.
5. Aguarde a publicação para acessar o endereço do GitHub Pages.

## Contatos e ajustes

As informações de contato ficam no objeto `ONG` no fim de `index.html`.
Os botões de contato abrem a seção correspondente e os dados não preenchidos aparecem como “Em breve”.

## Observação

Os recursos visuais foram mantidos conforme o arquivo HTML original fornecido.
